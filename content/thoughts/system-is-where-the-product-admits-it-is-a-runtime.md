## What System Is
System is the page where FleetCrown admits it is not just a CRUD app. It is a runtime.

That includes:

- health signals
- autopilot jobs
- runtime visibility
- memory summaries

## Why It Matters
If agents, crons, summaries, and background execution are part of the value proposition, then infrastructure state is not merely an implementation detail. It is part of the user’s mental model of trust.

The user needs to know whether the machine is alive, stale, blocked, or drifting.

## What Success Looks Like
System succeeds when it increases trust rather than merely exposing internals. The page should answer: is the machine healthy enough to rely on right now?
