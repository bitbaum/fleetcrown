# `@fleetcrown/bip`

Building in Public — **shared content contracts** for company/product surfaces:

- Markdown → typed blocks (tables, Mermaid fences, images, allowlisted video embeds)
- Roadmap / changelog / release TypeScript shapes

Studio dogfood lives here. Public OSS extract: sibling repo `bip-kit` (phase 2).

**Not for user-generated blogs.** UGC belongs on OrangeCat.
